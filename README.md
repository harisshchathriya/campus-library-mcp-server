# Campus Library MCP Server

A Campus Library MCP Server built using Python and the official Model Context Protocol (MCP) SDK.

## Use Case

**UC1 - Campus Library MCP Server**

The server provides MCP-based access to a campus library system for:

- Searching books
- Checking book availability
- Reserving books

## Technology

- Python 3.12
- MCP Python SDK 2.0.0
- SQLite
- MCP stdio transport
- MCP Inspector
- Python MCP client

## Project Status

Project foundation completed.

MCP tools, resources, database operations, validation, audit logging, testing, and MCP client integration will be implemented incrementally.
